# Edição Fortaleza

Workshop de Figma MCP no Fora do Frame, uma experiência UXFor (3º dia, workshops presenciais). Quarta, 18/11/2026, 18h00 às 19h40, Digital College Aldeota, Fortaleza.

Mesma base do TDC Florianópolis (o resto do repositório, mantido como histórico), com um passo novo no fim: cada pessoa sai com os tokens em JSON e o Card em HTML e CSS, que é de onde o workshop do Mateus Villain parte às 20h.

| Arquivo | Para quem | O que é |
|---|---|---|
| `guia-participante.md` | Participantes | Instalar, contas gratuitas, setup no Claude Desktop, os 8 passos com os prompts, alternativa Claude Code |
| `guia-voluntarios.md` | Voluntários | Papel na sala, marcas de relógio, regra de dupla, contingências |
| `roteiro.md` | Thiago | Grade de 18h00 a 19h40, bloco a bloco, com os slides |
| `checklist-thiago.md` | Thiago | O que fazer até segunda, na terça e no dia |
| `para-o-mateus.md` | Mateus Villain | O que a sala tem em mãos às 19h40, formato e conversão testada |
| `deck-ajustes.md` | Thiago | O que mudou na cópia do deck e o que falta decidir |
| `perguntas-gi.md` | Gi | Perguntas sobre a sala, prontas para copiar |
| `pasta-modelo/` | Participantes | Os três arquivos vazios do passo 7 |
| `qr-guia.svg`, `qr-guia.png` | Deck | QR para o `guia-participante.md` no GitHub |

Rede de segurança do passo 7: `handoff/`, na raiz do repositório, gerada de `src/tokens.css` por `npm run handoff:tokens`.

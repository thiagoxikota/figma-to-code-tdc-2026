# demo-card-sem-cor: cópia de demonstração para as 20h

É a pasta `handoff` sem o `tokens.css`. Serve para o Mateus mostrar, no telão, o Card "acendendo": aberto assim, o `Card.html` aparece sem cor e sem espaçamento; depois de `npx style-dictionary build --config config.json` dentro desta pasta, o `tokens.css` nasce e o Card ganha cor.

Ninguém da sala precisa desta pasta, e ninguém apaga arquivo da própria `handoff`: a pasta que cada pessoa conferiu continua inteira.

Os quatro arquivos são cópias idênticas dos de `handoff/`. Se o `handoff/` mudar, copie de novo.
